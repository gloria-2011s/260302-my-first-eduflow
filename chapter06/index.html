    처리장치와 저장장치 자세히 알기¶

    🎯 이 장에서 배우는 것¶

    • CPU, RAM, SSD/HDD의 역할을 비유로 설명할 수 있다
    • 앱 실행 시 데이터가 이동하는 흐름을 순서대로 말할 수 있다

    📚 핵심 개념¶

    🍳 주방에 비유하면 한 번에 이해돼요!¶

    컴퓨터 내부를 주방이라고 상상해 볼까요?

    1. CPU(중앙처리장치) = 요리사의 뇌 🧠 - "계란을 깨서 프라이팬에 올려야지!" 같은 판단과 계산을 하는 부품 - 컴퓨터의 모든 명령을 처리하는 핵심 두뇌예요

    2. RAM(주기억장치) = 요리대 🔪 - 요리할 재료를 꺼내 놓는 작업 공간 - 넓을수록 한 번에 많은 재료를 펼쳐놓을 수 있듯, RAM이 클수록 여러 앱을 동시에 실행할 수 있어요 - ⚡ 전원을 끄면 내용이 사라져요! (요리 끝나면 요리대를 치우는 것과 같아요)

    3. SSD·HDD(보조기억장치) = 냉장고 🧊 - 재료를 오래 보관하는 곳 - 전원을 꺼도 데이터가 안전하게 남아 있어요 - SSD는 빠른 냉장고, HDD는 용량이 큰 냉장고라고 생각하면 돼요

    4. ROM(읽기 전용 기억장치) = 기본 요리 레시피 책 📖 - 요리를 시작할 때 항상 참고하는 기본 레시피가 적힌 책 - 컴퓨터가 처음 켜질 때 필요한 기본 프로그램이 들어 있어요

    - 전원을 꺼도 내용이 사라지지 않고, 보통 사용자가 마음대로 바꾸지 않아요

    📱 앱을 실행하면 어떤 일이 벌어질까?¶

    스마트폰에서 게임 앱을 탭하는 순간, 이런 흐름이 일어나요.

    flowchart LR A["🧊 SSD/HDD\n게임 데이터 보관"] -->|"① 데이터를\n꺼내온다"| B["🔪 RAM\n작업 공간에 올림"] B -->|"② CPU가\n처리한다"| C["🧠 CPU\n계산·판단"] C -->|"③ 결과를\n보여준다"| D["🖥️ 화면\n게임 시작!"]

    냉장고에서 재료를 꺼내고(①) → 요리대에 올린 뒤(②) → 요리사가 요리하고(③) → 완성된 음식이 나오는 것과 똑같아요! 🍽️

    ⚠️ 주의할 점¶

    • RAM ≠ 저장장치: RAM은 임시 작업 공간이라 전원이 꺼지면 내용이 날아가요. 파일 저장은 반드시 SSD/HDD에!
    • CPU가 빨라도 RAM이 부족하면 느려요: 아무리 뛰어난 요리사도 요리대가 좁으면 요리가 느린 것과 같아요.

    ✅ 점검하기¶

    1. RAM은 전원을 꺼도 데이터가 남아 있다. (O/X)

    정답 확인❌ X — RAM은 전원이 꺼지면 데이터가 사라지는 임시 작업 공간이에요.

    2. CPU의 역할을 주방 비유로 설명하면?

    정답 확인🧠 요리사의 뇌! 어떤 명령을 어떻게 처리할지 판단하고 계산하는 역할이에요.

    3. 앱 실행 시 데이터 이동 순서를 말해 보세요.

    정답 확인SSD/HDD → RAM → CPU → 화면 출력 순서예요.
