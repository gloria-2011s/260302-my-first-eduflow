    3차시 정리 활동 – 내 스마트폰 속 소프트웨어 탐험¶

    🎯 이 장에서 배우는 것¶

    • 스마트폰 앱을 시스템 소프트웨어와 응용 소프트웨어로 분류할 수 있다
    • 하드웨어-소프트웨어-사용자의 관계를 한 문장으로 요약할 수 있다
    • 3차시 핵심 개념을 종합적으로 점검할 수 있다

    📚 핵심 개념¶

    개념: 소프트웨어 분류 총정리¶

    1. 비유로 시작: "스마트폰은 마치 건물과 같아요. 건물의 뼈대·전기·수도 같은 기반 시설이 시스템 소프트웨어이고, 그 안에 들어선 카페·서점·병원 같은 가게들이 응용 소프트웨어예요."

    2. 정확한 정의

    3. 시스템 소프트웨어: 하드웨어를 관리하고, 응용 소프트웨어가 돌아갈 수 있는 환경을 만들어 주는 소프트웨어 (예: Android, iOS)

    4. 응용 소프트웨어: 사용자가 특정 목적을 위해 직접 사용하는 소프트웨어 (예: 카카오톡, 유튜브)

    5. 관계 한 문장 요약 🔑

    "사용자는 응용 소프트웨어를 통해 명령하고, 시스템 소프트웨어가 이를 하드웨어에 전달하여 실행한다."

    flowchart LR A["👤 사용자"] -->|"앱 터치"| B["📱 응용 소프트웨어\n(카카오톡, 유튜브 등)"] B -->|"요청 전달"| C["⚙️ 시스템 소프트웨어\n(Android, iOS)"] C -->|"명령 실행"| D["🔧 하드웨어\n(CPU, 화면, 스피커)"]

    🔨 따라하기 – 내 스마트폰 앱 분류 활동¶

    Step 1: 앱 10개를 떠올려 분류하기 ✏️¶

    스마트폰을 꺼내(또는 머릿속으로 떠올려) 자주 쓰는 앱 10개를 골라보세요. 아래 예시처럼 시스템 / 응용으로 나눠 봅니다.

    • 시스템 소프트웨어 예시: 설정, Android(또는 iOS) 업데이트, 기기 관리자
    • 응용 소프트웨어 예시: 카카오톡, 유튜브, 네이버, 카메라 앱, 음악 앱, 게임, 지도, 계산기

    💡 팁: "이 앱이 없어도 폰이 켜질까?"라고 질문해 보세요. 없으면 폰이 안 켜지는 것 → 시스템, 없어도 폰은 켜지는 것 → 응용입니다!

    Step 2: 연결하기 퀴즈 🧩¶

    다음 소프트웨어의 종류와 주요 기능을 연결해 보세요.

    • Android → ( ? ) 소프트웨어 → 하드웨어 관리 및 앱 실행 환경 제공
    • 유튜브 → ( ? ) 소프트웨어 → 동영상 시청
    • iOS 업데이트 → ( ? ) 소프트웨어 → 운영체제 보안·기능 개선
    • 카카오톡 → ( ? ) 소프트웨어 → 메시지·통화

    정답: Android(시스템), 유튜브(응용), iOS 업데이트(시스템), 카카오톡(응용)

    ⚠️ 주의할 점¶

    • '설정' 앱 헷갈림 주의: 설정 앱은 운영체제(시스템 소프트웨어)의 일부예요. 앱처럼 보이지만 시스템에 속합니다!
    • 카메라 앱: 기본 카메라 앱은 운영체제에 포함되어 있지만, 사용자가 사진을 찍는 목적으로 쓰므로 응용 소프트웨어로 분류해요.

    ✅ 점검하기 – OX 퀴즈¶

    1. 시스템 소프트웨어가 없으면 응용 소프트웨어를 실행할 수 없다. (O / X)

    정답 확인⭕ O – 시스템 소프트웨어가 하드웨어를 관리해 줘야 응용 소프트웨어가 작동합니다.

    2. 카카오톡은 시스템 소프트웨어이다. (O / X)

    정답 확인❌ X – 카카오톡은 메시지 전송이라는 특정 목적의 **응용 소프트웨어**입니다.

    3. "사용자 → 응용 소프트웨어 → 시스템 소프트웨어 → 하드웨어" 순서로 명령이 전달된다. (O / X)

    정답 확인⭕ O – 이것이 바로 3차시 핵심 관계도입니다!
