    시스템 소프트웨어 vs 응용 소프트웨어¶

    🎯 이 장에서 배우는 것¶

    • 시스템 소프트웨어와 응용 소프트웨어의 역할 차이를 설명할 수 있다
    • 다양한 소프트웨어를 시스템/응용으로 분류할 수 있다
    • 두 소프트웨어가 어떻게 협력하는지 이해할 수 있다

    📚 핵심 개념¶

    개념: 두 종류의 소프트웨어¶

    비유로 시작해 볼게요! 🎭

    연극 공연을 떠올려 보세요. 무대 위 배우가 연기를 하려면, 무대 뒤 스태프가 조명을 켜고, 마이크를 연결하고, 무대 장치를 움직여야 해요.

    소프트웨어 세계도 똑같아요!

    🔧 시스템 소프트웨어 = 무대 스태프

    컴퓨터가 작동할 수 있도록 뒤에서 관리하는 소프트웨어

    • 운영체제(OS): Windows, macOS, Android, iOS
    • 드라이버: 프린터, 마우스 등 장치를 연결해주는 프로그램
    • 사용자가 직접 쓰는 게 아니라, 다른 프로그램이 돌아갈 환경을 만들어 줘요

    🎭 응용 소프트웨어 = 무대 위 배우

    사용자가 직접 사용하는 프로그램

    • 카메라 앱 📷, 카카오톡 💬, 유튜브 🎬
    • 한글/워드 📝, 게임 🎮, 계산기 🔢
    graph TB User["👤 사용자 (나!)"] App["🎭 응용 소프트웨어<br/>게임, 메신저, 카메라앱"] Sys["🔧 시스템 소프트웨어<br/>운영체제, 드라이버"] HW["🖥️ 하드웨어<br/>CPU, 메모리, 화면"] User --> App App --> Sys Sys --> HW

    💡 핵심 포인트: 응용 소프트웨어는 시스템 소프트웨어 위에서 돌아가요. 운영체제 없이는 게임도, 메신저도 실행할 수 없어요!

    🔨 따라하기¶

    Step 1: 파이썬으로 소프트웨어 분류하기¶

    # 소프트웨어를 종류별로 분류해보자!
시스템 = ["Windows", "Android", "프린터 드라이버"]
응용 = ["카카오톡", "유튜브", "마인크래프트", "한글", "카메라앱"]

print("🔧 시스템 소프트웨어:")
for sw in 시스템:
    print(f"   - {sw}")

print("🎭 응용 소프트웨어:")
for sw in 응용:
    print(f"   - {sw}")

print(f"\n시스템 {len(시스템)}개, 응용 {len(응용)}개!")

    실행 결과: 

    🔧 시스템 소프트웨어:
   - Windows
   - Android
   - 프린터 드라이버
🎭 응용 소프트웨어:
   - 카카오톡
   - 유튜브
   - 마인크래프트
   - 한글
   - 카메라앱

시스템 3개, 응용 5개!

    Step 2: 직접 추가해보기¶

    위 코드에서 응용 리스트에 자기가 자주 쓰는 앱을 추가해 보세요! 예: "인스타그램", "멜론"

    ⚠️ 주의할 점¶

    • "앱 = 응용 소프트웨어" 라고 생각하면 쉬워요. App은 Application(응용)의 줄임말이에요! 📱
    • 운영체제를 헷갈리지 마세요. Android는 앱이 아니라 시스템 소프트웨어예요!

    ✅ 점검하기¶

    1. "카카오톡"은 시스템 소프트웨어일까요, 응용 소프트웨어일까요?

    정답 확인응용 소프트웨어! 사용자가 직접 사용하는 프로그램이니까요 💬

    2. 운영체제(Windows, Android)가 없으면 어떻게 될까요?

    정답 확인응용 소프트웨어(게임, 메신저 등)를 실행할 수 없어요. 시스템 소프트웨어가 환경을 만들어줘야 하니까요!

    3. "프린터 드라이버"는 어떤 종류의 소프트웨어인가요?

    정답 확인시스템 소프트웨어! 프린터 하드웨어를 컴퓨터에 연결해주는 역할이에요 🔧
