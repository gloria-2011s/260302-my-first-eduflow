    네트워크란? – 컴퓨터끼리 대화하는 방법¶

    🎯 이 장에서 배우는 것¶

    • 네트워크가 무엇인지 비유를 활용해 설명할 수 있다
    • LAN과 WAN의 차이를 구분할 수 있다
    • 인터넷의 정확한 의미를 말할 수 있다

    📚 핵심 개념¶

    개념: 네트워크 🌐¶

    1. 비유로 시작

    네트워크는 마치 우편 시스템과 같아요!

    친구에게 편지를 보내려면 주소를 쓰고, 우체국을 거쳐, 친구 집까지 배달되잖아요? 컴퓨터도 똑같아요. 스마트폰에서 메시지를 보내면 Wi-Fi나 데이터를 통해 중간 장치(공유기, 기지국)를 거쳐 친구 폰에 도착합니다.

    2. 정확한 정의

    네트워크 = 두 대 이상의 컴퓨터(기기)가 서로 데이터를 주고받을 수 있도록 연결된 것

    3. 규모에 따른 구분

    graph LR A["🏫 LAN"] -->|여러 개 연결| B["🌍 WAN"] B -->|전 세계 연결| C["🌐 인터넷"]
    • LAN (근거리 네트워크): 교실, 집, PC방처럼 좁은 범위의 네트워크. 우리 집 공유기에 연결된 기기들이 바로 LAN이에요!
    • WAN (광역 네트워크): 도시와 도시, 나라와 나라를 잇는 넓은 범위의 네트워크
    • 인터넷: 전 세계의 네트워크를 하나로 연결한 거대한 네트워크

    🔨 따라하기¶

    Step 1: 파이썬으로 네트워크 확인하기¶

    내 컴퓨터의 이름(네트워크 주소)을 확인해 볼까요? 우편으로 치면 내 집 주소를 확인하는 거예요! 😄

    코드: 

    import socket

# 내 컴퓨터 이름 확인 (우편 시스템의 '내 주소')
my_name = socket.gethostname()
print("내 컴퓨터 이름:", my_name)

# IP 주소 확인 (네트워크에서의 고유 번호)
my_ip = socket.gethostbyname(my_name)
print("내 IP 주소:", my_ip)

    실행 결과: 

    내 컴퓨터 이름: MyComputer
내 IP 주소: 192.168.0.5

    💡 192.168로 시작하면 LAN 안의 주소라는 뜻이에요!

    📝 전체 코드¶

    import socket

my_name = socket.gethostname()
print("내 컴퓨터 이름:", my_name)

my_ip = socket.gethostbyname(my_name)
print("내 IP 주소:", my_ip)

    ⚠️ 주의할 점¶

    • 🚫 Wi-Fi = 인터넷이 아니에요! Wi-Fi는 기기를 공유기에 연결하는 무선 방식일 뿐이고, 인터넷은 전 세계 네트워크의 연결이에요. Wi-Fi가 되어도 인터넷이 안 될 수 있어요!
    • 🏠 IP 주소는 네트워크 환경마다 달라요. 실행 결과가 예시와 다른 게 정상입니다.

    ✅ 점검하기¶

    1. LAN과 WAN 중 우리 집 공유기에 연결된 기기들의 네트워크는?

    정답 확인LAN (근거리 네트워크)입니다. 집처럼 좁은 범위의 네트워크를 LAN이라고 해요.

    2. "Wi-Fi는 인터넷과 같은 뜻이다" – O일까 X일까?

    정답 확인❌ X! Wi-Fi는 무선 연결 방식이고, 인터넷은 전 세계 네트워크의 연결입니다. 서로 다른 개념이에요.

    3. 인터넷을 한 문장으로 설명하면?

    정답 확인전 세계의 네트워크를 하나로 연결한 거대한 네트워크입니다.
