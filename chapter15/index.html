    네트워크의 구성 요소와 데이터 전송¶

    🎯 이 장에서 배우는 것¶

    • 네트워크 주요 장비(라우터, 서버, 클라이언트)의 역할을 설명할 수 있다
    • 데이터가 패킷 단위로 나뉘어 전송되는 원리를 이해한다
    • 유선과 무선 네트워크의 차이를 구분할 수 있다

    📚 핵심 개념¶

    네트워크 구성 요소¶

    "네트워크는 마치 우편 시스템과 같아요!" 📮

    편지를 보낼 때를 떠올려 보세요. 편지를 쓰는 사람, 우체국, 편지를 받는 사람이 필요하죠? 네트워크도 똑같은 구조예요.

    • 클라이언트 🧑‍💻: 정보를 요청하는 기기. 여러분의 스마트폰이나 노트북이에요. 도서관에서 책을 빌리는 이용자와 같아요.
    • 서버 🏛️: 정보를 저장하고 제공하는 컴퓨터. 유튜브 영상을 보관하는 컴퓨터처럼, 요청이 오면 데이터를 보내주는 도서관 역할이에요.
    • 라우터 📬: 데이터를 목적지까지 길 안내해 주는 장비. 편지를 올바른 주소로 보내는 우체국과 같아요.
    flowchart LR A["🧑‍💻 클라이언트\n(이용자)"] -->|요청| B["📬 라우터\n(우체국)"] B -->|전달| C["🏛️ 서버\n(도서관)"] C -->|응답| B B -->|전달| A

    패킷: 데이터의 퍼즐 조각 🧩¶

    큰 사진 파일을 보낸다고 해볼까요? 통째로 보내면 길이 막혀요. 그래서 데이터를 패킷이라는 작은 조각으로 나누어 보내고, 도착지에서 다시 합칩니다.

    퍼즐을 조각조각 나눠서 각각 다른 길로 보낸 뒤, 도착하면 번호 순서대로 맞추는 거예요!

    유선 vs 무선¶

    • 유선 🔌: 랜선(케이블)으로 연결. 속도가 빠르고 안정적 (예: PC방 컴퓨터)
    • 무선 📡: Wi-Fi, 블루투스처럼 전파로 연결. 이동이 자유로움 (예: 스마트폰)

    🔨 따라하기¶

    Step 1: 패킷 전송 시뮬레이션¶

    # 메시지를 패킷으로 나누어 전송하는 체험
message = "안녕하세요반갑습니다"

# 2글자씩 패킷으로 나누기
packets = [message[i:i+2] for i in range(0, len(message), 2)]
print("📦 패킷으로 분리:", packets)

# 도착지에서 다시 합치기
result = "".join(packets)
print("✅ 수신 완료:", result)

    실행 결과: 

    📦 패킷으로 분리: ['안녕', '하세', '요반', '갑습', '니다']
✅ 수신 완료: 안녕하세요반갑습니다

    📝 전체 코드¶

    message = "안녕하세요반갑습니다"
packets = [message[i:i+2] for i in range(0, len(message), 2)]
print("📦 패킷으로 분리:", packets)
result = "".join(packets)
print("✅ 수신 완료:", result)

    ⚠️ 주의할 점¶

    • 패킷은 순서가 중요해요! 각 패킷에는 번호가 붙어서 도착 후 올바른 순서로 조립됩니다.
    • 라우터 ≠ 서버: 라우터는 길을 안내할 뿐, 데이터를 보관하지 않아요.

    ✅ 점검하기¶

    1. 라우터의 역할을 한 문장으로 설명하면?

    정답 확인데이터를 목적지까지 올바른 경로로 전달(길 안내)해 주는 장비입니다.

    2. 데이터를 작은 조각으로 나누어 보내는 단위를 무엇이라 하나요?

    정답 확인패킷(Packet)입니다.

    3. PC방 컴퓨터처럼 랜선으로 연결하는 방식은 유선/무선 중 무엇인가요?

    정답 확인유선 네트워크입니다.
