    입력장치와 출력장치 자세히 알기¶

    🎯 이 장에서 배우는 것¶

    • 대표적인 입력장치와 출력장치를 5가지 이상 말할 수 있다
    • 입력과 출력을 동시에 하는 장치를 설명할 수 있다

    📚 핵심 개념¶

    개념: 입력장치와 출력장치¶

    비유로 시작 🎤➡️🔊

    입력장치는 "컴퓨터의 귀와 눈" 이에요. 우리가 정보를 넣어주는 통로죠. 출력장치는 "컴퓨터의 입과 손" 이에요. 컴퓨터가 결과를 보여주는 통로예요.

    입력장치 🟢 — 사람 → 컴퓨터로 정보를 보내는 장치 - ⌨️ 키보드 : 글자를 입력 - 🖱️ 마우스 : 클릭과 이동 - 🎤 마이크 : 소리를 입력 - 📷 카메라(웹캠) : 영상을 입력 - ☝️ 터치패드 : 손가락으로 커서 이동 - 🎮 게임패드 : 게임 조작 신호 입력

    출력장치 🔵 — 컴퓨터 → 사람에게 결과를 보여주는 장치 - 🖥️ 모니터 : 화면을 출력 - 🔊 스피커 : 소리를 출력 - 🖨️ 프린터 : 종이에 인쇄 - 📳 진동모터 : 진동으로 알림 - 🥽 VR 헤드셋 : 가상 화면 출력

    🤔 입력 + 출력을 동시에?¶

    스마트폰 터치스크린을 떠올려 보세요! - 손가락으로 터치 → 입력 🟢 - 화면에 결과 표시 → 출력 🔵

    이렇게 하나의 장치가 두 역할을 동시에 하기도 해요.

    flowchart LR A["👆 손가락 터치<br>(입력)"] -->|신호 전달| B["📱 터치스크린"] B -->|화면 표시| C["👀 사용자가 봄<br>(출력)"]

    🔨 따라하기¶

    Step 1: 장치 분류 프로그램 만들기¶

    # 장치 이름을 입력하면 입력/출력을 알려주는 프로그램
장치 = {"키보드": "입력", "마우스": "입력", "마이크": "입력",
       "모니터": "출력", "스피커": "출력", "프린터": "출력",
       "터치스크린": "입력+출력"}

이름 = input("장치 이름을 입력하세요: ")

if 이름 in 장치:
    print(f"{이름}은(는) [{장치[이름]}] 장치입니다!")
else:
    print("등록되지 않은 장치예요.")

    실행 결과: 

    장치 이름을 입력하세요: 스피커
스피커은(는) [출력] 장치입니다!

    ⚠️ 주의할 점¶

    1. 헤드셋처럼 스피커(출력)+마이크(입력)가 합쳐진 제품도 있어요. 장치 자체가 아니라 기능 단위로 구분하는 게 정확해요!

    ✅ 점검하기¶

    1. 다음 중 출력장치는? ① 키보드 ② 마이크 ③ 프린터

    정답 확인③ 프린터 — 컴퓨터의 결과를 종이에 인쇄해주는 출력장치예요.

    2. 스마트폰 터치스크린이 입력장치이면서 출력장치인 이유는?

    정답 확인손가락 터치로 정보를 입력하고, 동시에 화면으로 결과를 출력하기 때문이에요.

    3. 웹캠(카메라)은 입력장치일까요, 출력장치일까요?

    정답 확인입력장치예요! 영상 정보를 컴퓨터에 넣어주는 역할을 합니다.
