    2차시 정리 활동 – 하드웨어 분류 도전! 🎮¶

    🎯 이 장에서 배우는 것¶

    • 다양한 하드웨어를 입력·처리·출력·저장 장치로 정확하게 분류할 수 있다
    • 스마트폰과 노트북의 하드웨어 구성을 비교할 수 있다
    • 종합 퀴즈로 2차시 핵심 개념을 확인할 수 있다

    📚 핵심 개념¶

    개념: 하드웨어 4대 분류¶

    하드웨어 분류는 마치 요리 과정과 같아요! 🍳

    • 입력 장치 = 재료를 가져오는 것 (키보드, 마우스, 마이크, 카메라)
    • 처리 장치 = 요리사가 요리하는 것 (CPU, GPU)
    • 출력 장치 = 완성된 요리를 내놓는 것 (모니터, 스피커, 프린터)
    • 저장 장치 = 냉장고에 보관하는 것 (SSD, HDD, USB, RAM)

    💡 기억법: 입으로 넣고 → 처리하고 → 출력하고 → 저장한다! ("입처출저")

    flowchart LR A["🎤 입력 장치"] --> B["⚡ 처리 장치"] B --> C["🖥️ 출력 장치"] B --> D["💾 저장 장치"]

    🔨 따라하기¶

    Step 1: 하드웨어 분류 프로그램 만들기¶

    아래 코드를 실행하면 하드웨어 이름을 입력했을 때 어떤 장치인지 알려줘요!

    # 하드웨어 분류 사전
분류 = {
    "키보드": "입력", "마우스": "입력", "마이크": "입력", "카메라": "입력", "터치스크린": "입력",
    "CPU": "처리", "GPU": "처리",
    "모니터": "출력", "스피커": "출력", "프린터": "출력",
    "SSD": "저장", "HDD": "저장", "USB": "저장", "RAM": "저장"
}

장치 = input("하드웨어 이름을 입력하세요: ")

if 장치 in 분류:
    print(f"✅ '{장치}'은(는) [{분류[장치]}] 장치입니다!")
else:
    print("🤔 목록에 없는 장치예요. 직접 분류해 보세요!")

    실행 결과: 

    하드웨어 이름을 입력하세요: 키보드
✅ '키보드'은(는) [입력] 장치입니다!

    Step 2: 스마트폰 vs 노트북 비교하기¶

    print("📱 스마트폰 vs 💻 노트북 하드웨어 비교")
print()
print("📱 스마트폰")
print("  - 입력: 터치스크린, 카메라, 마이크")
print("  - 처리: 모바일 AP (CPU+GPU 통합)")
print("  - 출력: 화면, 스피커")
print("  - 저장: 내장 메모리 (128~512GB)")
print()
print("💻 노트북")
print("  - 입력: 키보드, 터치패드, 웹캠")
print("  - 처리: CPU, GPU (분리형)")
print("  - 출력: 모니터, 스피커")
print("  - 저장: SSD (256GB~2TB)")

    🔍 차이점 발견! 스마트폰은 처리 장치가 하나로 합쳐져 있고, 노트북은 분리되어 있어요.

    ⚠️ 주의할 점¶

    • 터치스크린은 입력도 되고 출력도 돼요! 손가락으로 누를 때는 입력, 화면을 보여줄 때는 출력이에요 🖐️➡️🖥️
    • RAM은 저장 장치이지만, 전원이 꺼지면 데이터가 사라지는 임시 저장이에요!

    ✅ 점검하기¶

    1. 다음 중 "출력 장치"가 아닌 것은? ⓐ 모니터 ⓑ 프린터 ⓒ 마이크 ⓓ 스피커

    정답 확인ⓒ 마이크 — 마이크는 소리를 컴퓨터에 전달하는 입력 장치예요!

    2. OX 퀴즈: "CPU는 저장 장치이다"

    정답 확인❌ — CPU는 데이터를 계산하고 명령을 실행하는 처리 장치예요!

    3. 스마트폰의 모바일 AP가 노트북과 다른 점은?

    정답 확인스마트폰의 모바일 AP는 CPU와 GPU가 하나의 칩에 통합되어 있지만, 노트북은 CPU와 GPU가 분리되어 있는 경우가 많아요!
